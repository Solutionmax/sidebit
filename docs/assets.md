# Bit asset provenance

Bit is an original character. All artwork was generated for this project without third-party reference images and contains no brand logos.

- `Sources/Snipkin/Resources/pixel-scenes.png`: 1536×1024 RGBA atlas with six 512×512 transparent poses (typing, rubber-duck thinking, raised hand, trophy, sleeping, coffee balancing). It is the fallback when movie playback is unavailable. Runtime cropping leaves the file intact.
- `Sources/Snipkin/Resources/BitMovies/`: seven transparent HEVC films and matching posters. See [bit-movies.md](bit-movies.md) and [bit-alpha-encoding.md](bit-alpha-encoding.md).
- The app icon is drawn at build time from Bit's working poster (`scripts/make-icon.swift`).

Design brief: premium clay-toy pixel character, orange voxel body, dark rectangular eyes, graphite laptop, soft upper-left light, readable at 80 px.
